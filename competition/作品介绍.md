# AIRouter —— 作品介绍文档

> 开源鸿蒙大学生创新大赛 · 校园与创新应用赛道
> 版本：v1.0 · 日期：2026-08-16

## 一、项目概述

AIRouter 是一款基于 HarmonyOS（ArkTS）开发的远程 AI 编码助手网关客户端。用户通过手机、平板等鸿蒙设备，以 HTTPS 连接自建的 OpenCode Gateway 服务器，随时随地访问、恢复并继续运行在服务器上的 AI 编码助手（OpenCode）会话。

一句话：**把 AI 编码助手从桌面带到手机，让代码会话"装进口袋"。**

## 二、背景与痛点

- **痛点 1｜离开电脑就断档**：AI 编码助手（如 OpenCode、Cursor）通常跑在个人电脑上，人离开电脑后无法继续会话，跨设备续写体验割裂。
- **痛点 2｜数据自主可控**：云 IDE / 在线 AI 服务将代码与对话数据放在第三方云端，企业或开发者有数据合规顾虑。
- **痛点 3｜团队共享难**：个人电脑上的助手无法被团队统一部署、统一管理、统一审计。
- **痛点 4｜设备接入无信任机制**：简单密码登录无法满足"只允许我的设备接入"的安全诉求。

## 三、解决方案

AIRouter = HarmonyOS App + 自托管 Gateway + OpenCode AI 助手，形成"端—网—智"三层架构：

```
┌──────────────┐  HTTPS(8443)   ┌──────────────┐  opencode CLI   ┌──────────┐
│ HarmonyOS    │ ────────────▶ │ Gateway      │ ──────────────▶ │ AI 助手   │
│ AIRouter App │  HTTP(8080)   │ gateway/     │   websocket     │ (opencode)│
└──────────────┘               └──────────────┘                 └──────────┘
```

- **App 端**（ArkTS）：连接管理、设备注册/激活、会话列表与恢复、消息收发、多设备自适应布局、HUKS 密钥安全存储。
- **Gateway 端**（Node.js）：HTTPS/HTTP 双入口、设备注册/激活认证、令牌校验与限流、TURN/ICE 配置、OpenCode 会话恢复与消息转发、SQLite 设备与数据持久化。
- **服务器**：Linux ECS，systemd 托管，可一键脚本部署（含 coturn TURN/STUN）。

## 四、核心功能

| 功能 | 说明 |
|---|---|
| 多网关连接管理 | 保存多台服务器连接，一键切换 |
| 设备注册与激活 | 一次性注册码 + Ed25519 挑战签名，设备级准入 |
| 会话历史恢复 | 列出服务器端历史会话，随时恢复继续对话 |
| 消息实时收发 | 与 OpenCode 助手实时交互，支持任务/项目切换 |
| 跨端适配 | 手机、平板、二合一设备响应式布局 |
| TURN/ICE 穿透 | 面向复杂网络环境的连接能力预留 |

## 五、核心创新点

1. **设备级轻量信任体系**：新设备凭一次性注册码 `register`，再对服务器下发的 `challenge` 用 Ed25519 私钥签名完成 `activate`，之后所有请求携带签名令牌。实现"只认设备、不认密码"，可随时 `reregister` 回收设备。
2. **密钥不出安全硬件**：设备私钥经 HUKS（HarmonyOS 安全硬件）生成并存储，私钥永不离开芯片。
3. **传输与固定双重信任**：全程 HTTPS，App 内置固定 TLS 证书（certificate pinning），杜绝中间人。
4. **会话云端续接**：历史会话存储在自建服务器，多设备、多时间随时恢复，打破"一次会话绑一台设备"。
5. **自托管数据自主**：网关、数据库、AI 助手全部自建，数据不出自有服务器，天然满足隐私与合规诉求。

## 六、安全设计

- 注册码一次性、可轮换（`reregister`）
- Ed25519 挑战-响应认证，防重放
- 服务端签发令牌，定期刷新
- 接口限流，防暴力破解
- TLS 证书固定，防中间人
- 设备私钥 HUKS 硬件级保护

## 九、商业价值与前景

- **个人开发者**：一套服务器，全家设备用；按"自托管 AI 编码助手"订阅制售卖具备空间。
- **企业与团队**：团队统一网关、统一会话管理、统一审计，数据留在企业内网/自有云。
- **教育场景**：校内实验室共享 AI 编码助手，学生手机即可续写课程项目。
- **生态位**：补齐"本地/云端 AI 助手"之间缺失的"移动端访问自有 AI"环节。
